# Design Direction

## Visual Identity
- **Vibe**: Premium, clean, minimal, modern SaaS.
- **Typography**: Excellent, readable fonts with generous whitespace.
- **Color Palette**: Dark navy sidebar, light content workspace, subtle blue/lavender accents.
- **Components**: Rounded cards, soft borders, very restrained shadows.
- **Overall**: Should look like a polished AI product intelligence workspace, NOT a generic ChatGPT clone.

## Core Layout

### Left Sidebar
- Lenny Growth Assistant branding
- Navigation: New Conversation, Home, Explore, Saved, Artifacts, Settings
- Recent conversations list
- User/profile area

### Top Bar
- Global search / command bar
- Model/provider selector (Ollama / Cloud)
- Small status indicator

### Main Chat Area
- User messages & Assistant responses
- Clear headings and structured answers
- Source citations
- Follow-up suggestions
- "Convert to Ship 30 for 30" quick action

### Right Information Panel
- Tabs: Sources, Summary, Related, Artifacts
- Sources should appear as proper cards (not raw IDs)

### Bottom Composer
- Attachment/action area
- Prompt input
- Mode selector
- Send button
- Visible grounded-answer state

### Artifact Viewer
- Dedicated in-app viewer for full generated text/essays.
- Markdown and secure HTML rendering (no script execution).
